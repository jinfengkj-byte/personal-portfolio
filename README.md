# 个人 AI 产品作品集

这是我的个人 AI 产品作品集源码，用于展示从问题判断、产品设计到工程实现与上线交付的项目实践。

**在线作品集：** [https://portfolio.type16test.top](https://portfolio.type16test.top)

## 核心案例

- **OfferPilot**：AI 求职决策与行动系统
- **n8n 学习助手**：面向零基础用户的自动化学习产品
- **中国城市结构**：59 城交互研究地图
- **AI 情报自动化系统**：每日情报与创业雷达交付
- **在线测评产品矩阵**：独立部署的 MBTI 与八字产品

## 本地运行

需要 Node.js 22 或更高版本：

```bash
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:4173`。

本仓库是用于面试展示的轻量公开版本，保留主页源码、核心项目图片、样例报告与运行配置。服务器登录保护、部署备份、日志、本地依赖、环境变量，以及体积较大的城市研究附件均未包含在内；完整演示请以个人作品集网站为准。
